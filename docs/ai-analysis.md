# 선택적 AI 심층 분석 (5단계)

기본 분석·종합 보고서는 계속 무료 규칙 기반으로 생성합니다. AI는 이미 문서에서 추출한 근거를 사용해 **도입 관점·제약과 절충·작은 검증 제안**을 별도로 덧붙입니다. AI 성공 여부는 문서 조회 상태나 기본 분석 품질을 바꾸지 않으며, 기본 판단·근거·발행 장부를 대체하지 않습니다. 별도 SDK나 npm 의존성은 없습니다.

## 켜는 방법

기본값은 비활성입니다. 키만 등록해도 호출하지 않습니다. 로컬 프로세스 환경 또는 Actions의 다음 설정을 사용합니다. 키를 소스·커밋·공개 변수에 넣지 마세요. `.env` 파일을 자동으로 읽는 기능은 없습니다.

| 환경 변수 | Actions 설정 | 값·제한 |
|---|---|---|
| `OPENAI_API_KEY` | Repository secret | 사용자가 별도로 발급한 키 |
| `AI_ANALYSIS_ENABLED` | Repository variable | 정확히 `1`일 때만 새 호출 허용 |
| `AI_MAX_COST_USD` | Repository variable | **필수**, 실행당 USD 상한. 예: `0.05`. 0 초과·1 이하, 소수점 최대 6자리 |
| `AI_MAX_PROJECTS` | Repository variable | 기본 3, 실행당 1~10개. 기간이 다른 같은 근거는 한 번만 처리 |
| `AI_TIMEOUT_MS` | Repository variable | 요청당 기본 15000ms, 100~30000ms |
| `AI_TOTAL_TIMEOUT_MS` | Repository variable | 실행 전체 기본 45000ms, 요청 제한 이상·120000ms 이하 |

설정 후 평소처럼 `node scripts/collect.mjs`를 실행합니다. Actions에서는 collect 단계에 위 값이 전달됩니다. 정적 브라우저에는 키를 전달하지 않습니다. 이 구현 과정에서는 실제 키 등록·유료 호출·원격 워크플로 실행을 하지 않았습니다.

`AI_ANALYSIS_ENABLED`를 제거하거나 `0`으로 바꾸면 새 호출을 중단합니다. 이미 검증된 AI 해석은 문서·입력이 같고 확인 주기 안이면 재사용합니다. AI 본문까지 제거하려면 비활성 상태에서 해당 `usage.ai` 필드를 지우고 빌드할 수 있습니다. 기본 분석과 다른 데이터는 유지합니다.

## 근거와 출력 검증

1. 정상 조회했고 7일 확인 주기 안인 문서만 사용합니다. SHA 식별값과 참조 가능한 근거가 2개 이상 있어야 합니다. 전체 README 대신 실제 기본 분석이 참조하는 근거 최대 12개·입력 묶음 8000 UTF-8 바이트를 보냅니다. 전송 범위는 공개 저장소 이름·문서 경로/SHA·근거 발췌·미확인 항목입니다.
2. 고정 OpenAI Responses API에 도구 없이 구조화 JSON을 요청합니다. 원문의 지시는 신뢰하지 않는 자료로 취급하고 실행하지 않습니다. `store: false`를 사용하지만 이것이 제공자의 모든 보관 정책을 변경한다는 뜻은 아닙니다.
3. 정확히 세 종류의 한국어 해석, 필드·길이·근거 ID·원문에 실제 포함된 인용을 검사합니다. 새 수치 주장, URL·HTML·명령 블록과 명백한 실행 보증 표현 등을 거부합니다.
4. 별도의 모델 요청이 해석과 문서 근거를 대조합니다. 선택 조건의 필수화, 미지원 기능의 지원 단정, 근거 없는 비교 등을 검토하고 세 해석 모두 통과해야 채택합니다. 부분 채택하지 않습니다.
5. 저장·빌드 전에 근거 참조, 입력 지문, 결과 해시를 다시 검사합니다. 결과 해시는 검증 후 우발적 변경을 탐지하는 용도이며 신뢰할 수 있는 서명은 아닙니다. 빌드에서 모델 검토를 다시 실행하지 않습니다.

인용 일치는 해석의 타당성을 보증하지 않습니다. 별도 모델 검토도 같은 모델의 확률적 판단이므로 오류가 남을 수 있습니다. 화면은 이를 **선택적 AI 심층 분석**으로 구분하고 실행·성능 검증이나 사실 보증으로 표시하지 않습니다. 연결 문서 추가 수집, 실제 설치·실행, 외부 비교 조사, 자유로운 번역 보고서는 이번 범위에 포함하지 않습니다.

## 비용·시간 제한

모델은 `gpt-5.4-mini-2026-03-17`로 고정합니다. 임의 모델로 바꾸면 비용 계산이 달라지므로 허용하지 않습니다. 2026-11-11 확인한 일반 텍스트 입력 $0.75·출력 $4.50/백만 토큰을 사용합니다. [공식 모델·가격 문서](https://developers.openai.com/api/docs/models/gpt-5.4-mini), [Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create), [구조화 출력](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)를 기준으로 구현했습니다. 가격표 재검토 없이 **2026-12-11 09:00 KST부터 새 호출을 중단**하며 기존 유효 캐시는 재사용합니다.

첫 요청 전에 생성과 추가 검토 **두 요청의 최대 예상 비용을 함께 예약**합니다. 입력은 직렬화한 요청의 UTF-8 바이트 수에 여유 4096 토큰을 더한 보수적 추정이고, 검토 입력은 최대 24000바이트에 같은 여유를 더합니다. 출력은 생성 1800·검토 600토큰으로 제한합니다. 예약액이 상한을 넘으면 첫 요청도 보내지 않습니다. USD 계산은 정수 단위를 사용하고 실패·거부·시간 초과 뒤에도 예약을 반환하지 않습니다. 실제 응답 사용량이 예약 범위를 벗어나면 이후 AI 처리를 중단합니다.

이는 고정 단가·입력 추정 가정에 따른 **애플리케이션의 실행당 상한**입니다. 계정 전체·하루 누적 청구 상한이 아니며 동시 실행과 수동 재실행은 각각 별도 예산입니다. 공급자 측 청구의 절대 보증도 아닙니다. 예를 들어 `0.05`를 매일 실행하면 월 전체 한도가 `0.05`인 것은 아닙니다. 운영 계정의 지출 관리도 별도로 설정해야 합니다. 낮은 상한에서는 모든 프로젝트가 규칙 분석으로 남을 수 있습니다.

요청 제한은 응답 본문 수신까지 포함합니다. 전체 시간은 AI 제어기 생성부터 계산하므로 앞선 문서 처리 시간도 포함됩니다. 시간 초과 시 요청을 중단하고 이후 새 AI 호출도 멈춥니다. 이미 도착한 요청이 공급자에서 계속 처리·청구될 수 있어 예약액을 돌려주지 않습니다. 프로젝트당 최대 두 요청이며 AI 요청은 429·5xx를 포함해 자동 재시도하지 않습니다. 응답은 최대 32768바이트로 제한합니다.

## 실패와 재사용

설정 오류·예산/개수/시간 초과·문서 부족·HTTP/네트워크 오류·잘린 JSON·거부·잘못된 인용·모델 근거 검토 실패 모두 규칙 기반 분석으로 복구합니다. 거부된 후보 본문과 원본 API 오류는 저장하지 않습니다. 화면에는 안전한 실패 사유만 표시합니다. AI 오류만으로 발행 전체를 중단하지 않습니다.

정상 해석은 모델·AI 버전·규칙 분석 버전·문서 SHA·분석 입력·실제 근거 묶음의 지문이 같으면 최신 보고서에서 재사용합니다. 기간이 달라도 같은 지문은 실행 중 한 번만 호출합니다. 문서 확인 시각만 바뀌고 SHA가 같으면 재사용할 수 있습니다. 문서/입력이 바뀌거나 오래됐으면 이전 AI 본문을 숨기고 새 검증 또는 규칙 복구를 수행합니다. 실패한 항목은 다음 수집에서 조건과 예산이 허용할 때 다시 시도할 수 있습니다. 로그에는 호출 프로젝트 수·완료 수·예약/응답 사용량 환산액·상한만 남기며 키·요청 원문·응답 원문은 남기지 않습니다.

## 검증 범위

`test/ai.test.mjs`는 실제 유료 호출 없이 Responses 형태의 모의 응답으로 기본 비활성, 두 요청 성공, 인용/수치/스키마 거부, 의미 검토 거부, 비용 사전 예약, 타임아웃과 중단, 전체 시간, HTTP/본문/사용량 오류, SHA 재사용·무효화, 발행 복구를 검증합니다. `test/web.test.mjs`는 별도 AI 표시와 오래된/잘못된 AI 본문 차단을 검사합니다.

로컬 브라우저에서도 실제 수집 파이프라인에 모의 응답을 주입해 채택·거부 카드, Enter/Space 근거 펼치기, 320px 모바일 줄바꿈과 가로 넘침 없음, 콘솔 오류 없음을 확인했습니다. 검증 서버는 공개 데이터·배포 파일에 모의 AI 본문을 기록하지 않고 종료했습니다. 실제 유료 API의 계정 권한·지연·응답 품질은 검증하지 않았으며 모의 검증 통과가 실제 모델 해석 품질을 증명하지 않습니다.
